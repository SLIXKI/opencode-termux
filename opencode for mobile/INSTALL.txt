====================================================
  opencode-mobile  —  INSTALL GUIDE
  Brought to you by @FeaturisticLeaks X @slixki
====================================================

--------------------------------------------------
STEP 1 — Install Termux (one time only)
--------------------------------------------------
Install the Termux app from F-Droid (NOT Google Play):

    https://f-droid.org/packages/com.termux/

--------------------------------------------------
STEP 2 — Paste this ONE line and press Enter
--------------------------------------------------
Open Termux, then paste this single line:

    curl -fsSL https://raw.githubusercontent.com/SLIXKI/opencode-termux/main/install.sh | bash

That is the entire install. It does everything by itself:
packages, the latest opencode, free models, memory,
the AI shortcut and the keyboard button.

The only things you will ever need to do:

  * if a "tap ALLOW" dialog appears  ->  tap ALLOW
  * when it asks for your OpenCode key -> paste it,
    or just press Enter to skip (free models work
    without a key; a key only raises your limits)

    free key, no card required:
    https://opencode.ai/auth
    Sign in or register -> tap "API key" -> copy

It takes a few minutes. Let it finish.

--------------------------------------------------
STEP 3 — Use it (forever)
--------------------------------------------------
Close Termux COMPLETELY (swipe it away), open it
again, then type:

    AI

That opens opencode. Type what you want to build.

Useful:

    AI            open opencode here
    AI myapp      create/open the project "myapp"

====================================================
TO UPDATE (or fix almost any problem)
====================================================
Just run the same one line again. It updates
opencode in place and is safe to repeat:

    curl -fsSL https://raw.githubusercontent.com/SLIXKI/opencode-termux/main/install.sh | bash

This is also the fix if you ever see:

    OpenCode 1.18.0 or newer is required to use
    the free tier

That message means your opencode is too old for the
free models. Re-running the line above installs the
latest version.

====================================================
TO UNINSTALL
====================================================
    curl -fsSL https://raw.githubusercontent.com/SLIXKI/opencode-termux/main/uninstall.sh | bash

It asks first. Your projects under ~/opencode are
KEPT unless you explicitly agree to delete them.

====================================================
NO INTERNET FOR THE ONE-LINER? (offline install)
====================================================
If you were sent the zip instead, put it in your
Downloads folder, then run these ONE AT A TIME:

    termux-setup-storage

    cd ~/storage/downloads

    unzip -o opencode-mobile-v2.0.0.zip

    cd opencode-mobile

    bash install.sh

The zip creates a folder named "opencode-mobile" and
puts everything inside it — that's the folder you
cd into.

(If an OLD copy once left loose files in Downloads
with no opencode-mobile folder, delete those loose
files first. In your phone's file manager, delete:
install.sh, uninstall.sh, config, README.md, GUIDE.md,
requirements.txt, INSTALL.txt — then unzip again.)
